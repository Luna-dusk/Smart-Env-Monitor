LVGL 仪表盘提示词 — 240×320 假玻璃版
把下面「完整版主提示词」整段复制，粘贴给任意代码 AI（或 Muse / Cursor 等工具），就能让它按你已经定好的预览，一次生成对应的 LVGL 代码。不用再口头解释布局、颜色和玻璃效果，关键数值都写死在提示词里了。
怎么用
先改提示词开头方括号里的占位符，最重要的是 [LVGL_VERSION]：你用 8.3 就填 8.3，用 9.x 就填 9.x。不知道版本就先保留占位符，让 AI 先问你，不要让它猜。
整段复制完整版，不要只抄中间几段。分区坐标、背景光晕和玻璃透明度是互相咬合的，少一段就容易跑偏。
拿到代码后先在你的 ESP32-S3 板子上编译一次。提示词只能把需求说准，不能代替上板验证，字体和驱动对不上时把报错原样发回给 AI 改。
只想快速试一版时，用文末的「简版提示词」。简版省字，但约束弱一些，适合改样式，不适合第一次生成。
重点提醒：提示词里凡是写了具体数字的地方（坐标、色值、透明度）都不要随手改。那是按 240 宽 × 320 高重新算过的，早期按 480×320 写的坐标贴到这块屏上，光晕会跑到屏外。
完整版主提示词（可直接复制）
复制下面代码块里的全部内容，改好方括号占位符后直接发送：
你是一名熟悉 ESP32-S3 + LVGL 的嵌入式工程师。请为我生成一个可直接编译的 LVGL 仪表盘界面，严格按下面的规格实现，不要自行改布局、改颜色或换效果。

基本信息：
- LVGL 版本：[LVGL_VERSION: 8.3 / 9.x，二选一，生成前必须确认，不要猜]
- 芯片与屏幕：ESP32-S3（N16R8，16MB Flash / 8MB PSRAM），LCD 为竖屏 240 宽 × 320 高，RGB565。
- 坐标规则：全部使用绝对坐标定位，左上角为 (0,0)。禁止响应式缩放、禁止百分比布局、禁止按 480×320 或其他分辨率推算坐标。
- 界面为单页，一页装完，不做翻页，不做滚动。

分区布局 — 严格按此表落位：
1. 状态栏：y 0~23，高 24。左：WiFi 图标；中：闹钟图标；右：电量/连接状态图标。
2. 时钟区：y 26~100，高 74。第一行用 LV_FONT_MONTSERRAT_48 显示时间「12:34」，居中；第二行用 16px 中文字体显示「2026-11-18 星期三」。
3. 温湿度卡：y 104~152，高 48，卡片 x=12、宽 216。左右分栏，中间一条 1px 半透明分隔线。左：25℃，标签「温度」；右：45%，标签「湿度」。
4. 空气质量卡：y 156~214，高 58，卡片 x=12、宽 216。上行三值横排：TVOC 533 µg/m³、HCHO 83 µg/m³、eCO2 933 ppm，数值和单位分开排，单位字号更小。下行：10 格等级色条，点亮 7 格，点亮色为橙色渐变 #ffb648 → #ff8a3d，右侧文字「轻度污染」，橙色。
5. 天气卡：y 218~266，高 48，卡片 x=12、宽 216。左：天气图标 +「多云」+「25℃」；右对齐：上行「18~27℃」，下行城市「广州」。
6. 底栏：y 270~318，高 48，卡片 x=12、宽 216。左：闹钟图标 +「07:00」+ 绿色 ON 标记；中间一条竖分隔线；右：绿色对勾标记 +「SNTP 已同步」，文字不得被截断。
卡与卡之间、卡与时钟区之间按上表留空隙，不要把控件贴边或互相重叠。

背景 — 深蓝海雾，二选一，默认用代码法：
代码法（默认，0 额外 PSRAM）：
- 屏幕竖向渐变：#1d324e → #13253c → #0d1b2d，即 bg_color=0x1d324e、bg_grad_color=0x0d1b2d、LV_GRAD_DIR_VER、bg_opa=LV_OPA_COVER。
- 在渐变之上、卡片之下，再加 3 团静态柔光。柔光用「圆形对象 + 大阴影」模拟（LVGL 没有径向渐变）：圆本身 bg_opa 按下表，阴影宽 40、阴影色同圆色、shadow_opa=LV_OPA_50，对象不可点击、不可滚动，创建后不要再移动或做动画。
· 左上钢蓝：位置 (-30,-50)，尺寸 130×130，颜色 0x3a7ca5，LV_OPA_30
· 右上青蓝：位置 (160,-30)，尺寸 110×110，颜色 0x2e8b9a，LV_OPA_30
· 右下深蓝：位置 (140,200)，尺寸 120×120，颜色 0x274b73，LV_OPA_40
光晕故意一半探出屏幕边缘，这是刻意的，不要把它「修正」回屏内。
- 创建顺序必须是：先背景渐变 → 再 3 团柔光 → 最后才是卡片和文字。LVGL 按创建顺序绘制，顺序错了玻璃下面就没有颜色可透。
图片法（仅当我明确说要用图片法时才用）：
- 背景图必须做成 240×320，用 LVGL Image Converter 转成 C 数组，格式选 CF_TRUE_COLOR / RGB565，图片以 const 存 Flash，不要用 PNG 解码，不要把图片放进 PSRAM。
- LVGL 9.x 用 lv_image_create / lv_image_set_src；LVGL 8.x 用 lv_img_create / lv_img_set_src。生成后用 lv_obj_move_background 把背景放到最底层。

假玻璃卡片 — 只做假玻璃，禁止真模糊：
统一写一个辅助函数，所有卡片和底栏都调用它，不要每张卡各写一套样式：
static lv_obj_t *glass_card(lv_obj_t *scr, int y, int h);
函数内部固定做：lv_obj_create(scr)，尺寸宽 216、高为传入的 h，位置 (12, y)，并设置以下样式（选择器用 0 / LV_PART_MAIN，按所填 LVGL 版本写）：
- 半透明底：bg_color 为白色 lv_color_white()，bg_opa = 66（约 26%，这是定死的值，不要换成 LV_OPA_70 或百分比猜测）。
- 顶部高光靠渐变本身实现：bg_grad_color = 0xdfe9f2，bg_grad_dir = LV_GRAD_DIR_VER。不要再额外创建一个高光对象叠在卡片上。
- 亮边：border_width = 1，border_color 为白色，border_opa = 72。
- 圆角：radius = 14。
- 浅阴影：shadow_width = 10，shadow_ofs_y = 4，shadow_opa = LV_OPA_20。不要开大阴影、不要做发光外框。
- 内边距 pad_all = 8，清除 LV_OBJ_FLAG_SCROLLABLE。
严禁使用实时背景模糊、backdrop blur、lv_snapshot 截图模糊、高斯模糊或逐帧重绘背景。假玻璃只靠「半透明底 + 渐变高光 + 1px 亮边 + 浅阴影」这四样，不需要任何额外帧缓冲。

字体与图标：
- 时间数字用 LV_FONT_MONTSERRAT_48，不要用中文字体画数字时间。
- 中文只用 16px 子集字体。子集必须包含这些字：年月日星期一二三四五六温度湿度多云广州轻度污染已同步闹钟，以及界面上实际出现的其他中文。生成代码时请单独列出完整的子集字符清单，方便我去做字体文件；清单之外的中文不要出现在界面上。
- 不要使用 emoji 字体，不要假设系统有 emoji。原文案里的图标含义改用 LV_SYMBOL 或简单的自绘/占位图标函数实现：WiFi、电量、闹钟、温度、水滴、天气云、定位、对勾、ON 状态。每个图标留一个可替换的函数或宏，方便我之后换成自己的图标字库或图片。

刷新接口：
请同时给出头文件和源文件，并提供以下接口（命名可按我的工程习惯微调，但功能不能少）：
- void ui_dashboard_create(void); // 只负责创建全部控件，只调用一次
- 一个数据结构体（例如 ui_dashboard_data_t），字段至少包含：时间、日期、星期、温度、湿度、TVOC、HCHO、eCO2、空气等级、天气状况、天气当前温度、最低温、最高温、城市、闹钟时间、闹钟开关、SNTP 是否已同步、WiFi 是否连接、电量。
- void ui_dashboard_update(const ui_dashboard_data_t *data); // 或按字段拆成几个 update 函数
要求：
- 时钟用 1 秒的 lv_timer 单独刷新，只改时间/日期标签。
- 传感器和天气数据由外部调用 update 函数刷新，不要在 LVGL 任务里阻塞等待传感器、HTTP 或 SNTP。
- 刷新时只更新变化的标签，不要每次重建控件、不要全屏重绘、不要在每次刷新里做动态内存分配。


交付物 — 请一次给全：
1. 完整的.h 和.c 文件代码，可直接加入 ESP-IDF 工程编译，不要只给片段或伪代码。
2. lv_conf.h 需要打开的配置清单，例如 Montserrat 48 字体、渐变、阴影等，写清配置宏的名字。
3. 中文字体子集字符清单。
4. 一段简短的 PSRAM 估算说明。
5. 一段接入示例：说明在 app_main / LVGL 任务里在哪里调用 ui_dashboard_create()，以及数据更新时在哪里调用 update。


禁止事项：
- 禁止真模糊、禁止 lv_snapshot、禁止 PNG 解码。
- 禁止出现 480×320 的坐标、尺寸或图片说明。
- 禁止在刷新路径里反复 malloc/free。
- 禁止把背景做成动画。
- 如果 LVGL 版本未确认，或某个字体/图标在该版本下没有现成支持，先明确指出并给出替代方案，不要编造不存在的 API。

简版提示词
赶时间、或只是让 AI 改个样式时用这一版。它保留了最容易出错的几项，细节约束不如完整版严。
请用 LVGL [LVGL_VERSION: 8.3 / 9.x] 为 ESP32-S3 生成一个 240×320 竖屏仪表盘的完整 .h/.c 代码，绝对坐标、单页不滚动。分区：状态栏 y0~23（WiFi/闹钟/电量）；时钟 y26~100，Montserrat 48 显示 12:34，下行 16px 中文子集字体显示 2026-11-18 星期三；温湿度卡 y104~152（x=12、宽216，左右分栏 25℃ / 45%）；空气卡 y156~214（TVOC 533 µg/m³、HCHO 83 µg/m³、eCO2 933 ppm，下行 10 格色条亮 7 格橙色 +「轻度污染」）；天气卡 y218~266（多云 25℃，右对齐 18~27℃ / 广州）；底栏 y270~318（07:00 ON | SNTP 已同步，不得截断）。背景用深蓝海雾：竖向渐变 #1d324e → #13253c → #0d1b2d，加 3 团静态柔光（圆+阴影宽40）：(-30,-50,130,0x3a7ca5,LV_OPA_30)、(160,-30,110,0x2e8b9a,LV_OPA_30)、(140,200,120,0x274b73,LV_OPA_40)，先背景后卡片。卡片只做假玻璃，禁止真模糊和 lv_snapshot：统一 glass_card(scr, y, h) 函数，宽216、x=12、圆角14、白色 bg_opa=66、渐变到 0xdfe9f2 竖向、1px 白边 border_opa=72、阴影宽10/偏移y 4/opa LV_OPA_20，高光靠渐变本身不要另加对象。中文用 16px 子集字体并列出子集清单，图标用 LV_SYMBOL 或占位函数、不要 emoji 字体。另给 ui_dashboard_create() 和带数据结构体的 ui_dashboard_update() 接口（时钟用 1s lv_timer 单独刷，刷新不重建控件、不全屏重绘、不反复分配内存），并附 lv_conf 配置清单、PSRAM 估算和接入示例。不要用 480×320 的任何坐标，不要 PNG 解码，不要编造不存在的 API。
用之前要知道的几件事
中文字体是子集，不是全字库。 16px 中文字体如果做全字库，Flash 占用会大很多，所以只把界面上真正出现的字打进字体文件。换文案时（比如城市从广州换成别的城市、天气从多云换成小雨），新字不在子集里就会显示成空白或方框，要先把新字补进子集重新生成字体。
图标不要指望 emoji。 预览图里的温度计、水滴、云朵在网页上是现成图标，到了 LVGL 上没有 emoji 字体可用。提示词已经让 AI 用 LV_SYMBOL 或占位图标函数顶上，效果会比预览朴素一些；想要预览那个样子，后面需要你自己准备一套小图标图片或图标字库替换进去。
LVGL 8 和 9 的差别主要在图片接口。 9.x 用 lv_image_create / lv_image_set_src，8.x 用 lv_img_create / lv_img_set_src，其余本界面的样式接口两版基本一致。所以版本号一定要填对，这是最常见的编译报错来源。
假玻璃几乎不占 PSRAM，真模糊才贵。 这块屏一帧 RGB565 是 240 × 320 × 2 = 153,600 字节，约 150KB；正常 LVGL 用 1/10 屏的 draw buffer 约 15KB，可以放在片内 SRAM。假玻璃只是改样式，0 额外帧缓冲；真模糊要多备源帧和结果帧，约多 300KB 还要逐帧计算。这也是提示词里写死禁止真模糊的原因。
生成的代码仍要上板验证。 这份提示词是把已经定稿的预览和修正过的背景代码翻译成需求描述，数值都对齐过，但没有哪份提示词能保证一次编译通过。第一次编译的报错（多半是版本接口或字体）把原文发回给同一个 AI，让它按报错改，不要换一个 AI 从头再来。
背景不要做成动的。 光晕和渐变在提示词里是静态创建的。背景一旦动起来，LVGL 就要不停重绘全屏，在 ESP32 上帧率和功耗都会吃不消，智能音箱还要同时放音频，更要避开。
